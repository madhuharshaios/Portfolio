## 🌟 Visual Theme & Design Features

- **Refined Natural Dark Palette:** Deep matte obsidian black (`#0c0d10`, `#07080a`) accented with warm brushed bronze (`#c89758`), desert sand (`#dfb27e`), and champagne titanium tones.
- **Glassmorphism:** Frosted translucent cards with subtle borders (`backdrop-filter: blur(16px)`).
- **Interactive Features & Micro-Animations:**
  - Dynamic typed title effect in hero section (with reduced-motion accessibility support).
  - Floating ambient gradient orbs and rotating glowing avatar aura.
  - Smooth scroll-spy navigation with active link indicators.
  - Scroll-triggered reveal animations via `IntersectionObserver`.
  - Animated skill progress indicators.
  - Project category filter (Data Analysis, Machine Learning, NLP).
  - Interactive certificate lightbox modal with authentic credential verification links.
  - CV modal with preview and direct PDF download.
  - Client-side contact form with validation and `mailto:` action.
  - Floating back-to-top button.
- **Zero Heavy Dependencies:** Clean, fast vanilla HTML5, CSS3, and JavaScript.

## 🚀 Local Development

1. Clone or download this repository:
   ```bash
   git clone https://github.com/madhuharshaios/Portfolio.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Portfolio
   ```
3. Open in your browser:
   - Double click `index.html`, OR
   - Run with Python: `python -m http.server 8000` and visit `http://localhost:8000`, OR
   - Run with VS Code Live Server extension.
